# Code of Conduct

DiffBeacon contributors are expected to make participation respectful, constructive, and accessible. Harassment, discrimination, threats, personal attacks, and deliberate disruption are not acceptable.

Maintainers may remove comments, close discussions, or restrict participation when conduct violates
this standard.

There is **no configured reporting channel for conduct concerns**: this project has not published
a moderation address, and neither GitHub private vulnerability reporting nor the issue tracker is
conduct intake. Private vulnerability reporting is enabled for this repository and is the right route
for security reports, as [`SECURITY.md`](SECURITY.md) describes, but it is a vulnerability intake and
is deliberately not reused for conduct complaints. The issue tracker is public, so it is not a place
to report misconduct privately either. Reaching a maintainer through a channel you already have is
the only option today.

Establishing a published, monitored conduct intake is a **post-release governance improvement**, not a
prerequisite for the `v0.1.0` release; the maintainer decision of 2026-10-05 is recorded in
[`docs/audits/stage13-release-policy-decision.md`](docs/audits/stage13-release-policy-decision.md) and
[`docs/releasing.md`](docs/releasing.md) §0 reflects it. This file will name a channel only once one
actually exists and has been verified — it does not name one now.
